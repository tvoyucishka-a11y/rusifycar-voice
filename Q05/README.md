# Q05: что нужно прислать для переноса русского голосового

Работа идёт в облаке — файлы с вашего компьютера (`C:\...`, `D:\...`) оттуда не видны.
Всё нужное надо загрузить в этот репозиторий на GitHub.

## 1. Дамп Q05
Перетащите папку с дампом (например `D:\Q05\q05 sys\q05 sys`) на **`2_q05_dump_pack.bat`**.
Скрипт сам найдёт штатный голосовой (`WT_TSpeech` / `com.tinnove.wecarspeech`), `build.prop`,
onnxruntime и автомобильные framework‑jar'ы, добавит полный список файлов дампа (`listing.txt`)
и порежет всё на куски по 20 МБ → папка **`q05_dump_upload`** рядом со скриптом.

## 2. Актуальный мод Q07 (v10)
Перетащите папку `v10` на **`pack.bat`** → рядом с ней появится **`v10_upload`**.
(Если в `v10` только `update.q7patch` и .bat/.ps1 — можно загрузить её как есть, без нарезки.)

## 3. Загрузка на GitHub
Через сайт: репозиторий → **Add file → Upload files** → перетащить файлы из `*_upload`
(до 100 файлов и до 25 МБ на файл за один раз; если кусков больше 100 — несколько заходов) → **Commit changes**.
Через git: скопировать папки `*_upload` в клон репозитория, `git add -f <папка>`, `git commit`, `git push`.
Ветка любая (можно `main`).

## Необязательно: снять с самой машины Q05
Если Q05 рядом и подключён по ADB — **`1_q05_collect.bat`**: заберёт установленную версию
голосового и лог штатного нажатия кнопки на руле → папка `q05_stock_upload`.
