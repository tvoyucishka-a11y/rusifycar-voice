# Русский голосовой для Changan Q05 (WT_TSpeech) — сборка v1

Перенос русского голосового с Q07 на Q05: **GigaAM** (распознавание русского),
**TeraTTS** (русская озвучка), **Ru2Zh** (перевод команд на китайский для исполнения).
Основано на штатном голосовом Q05 `com.tinnove.wecarspeech` 2.5.3.19_beta, подпись — тот же
AOSP platform test‑key, что у штатного (обновление системного приложения, root не нужен).

## Установка
1. `1_join.bat` — соберёт `SpeechAssistant-q05-ru.apk` из `parts\` (должно получиться **816 677 073 байта**;
   контрольная сумма в `SpeechAssistant-q05-ru.apk.sha256`).
2. Подключить голову Q05 по ADB (USB или `adb connect IP:PORT`).
3. `2_install.bat` — поставит мод и перезапустит ассистента. Первый запуск ~1 минуту (распаковка моделей).
4. Нажать кнопку голосового на руле (или сказать штатное слово пробуждения), дождаться реакции,
   сказать команду по‑русски и замолчать.

## Проверка логом
`3_log.bat` — пишет `q05_log.txt`. Скажите «открой окно водителя», замолчите. Ожидаемое:
- `Q05Bridge: listen start` — началась наша запись (нажата кнопка/пробуждение);
- `GigaAsr … feed …` / `ASR: [открой окно водителя]` — GigaAM распознал русский;
- `Q05Bridge: injectZh -> startSrByText: 打开主驾车窗` — команда ушла штатному движку → машина исполняет;
- `IflytekTTSEngine … RuIssTts` / русская озвучка ответа.

Если что‑то не так — пришлите `q05_log.txt`.

## Откат
`4_rollback.bat` — удаляет мод, возвращается штатный голосовой из /system (versionName 2.5.3.19_beta).

## Это v1 — чего ждать
Это первая сборка под Q05, собранная без доступа к самой машине. Как и на Q07 (там мод прошёл
v2→v10 по логам), v1 почти наверняка потребует правок по `q05_log.txt` с вашей машины. Вероятные
места донастройки:
- **Звук.** Точка перехвата — поток iFlytek после шумоподавления; чистое моно достаётся штатным
  `LibISSSE2.extractAudio(type=2)`. Если в логе `feed … rms` не растёт при речи — поправлю тип потока.
- **onnxruntime.** В APK версия 1.17 от мода заменяет штатную 1.14 (C‑API обратно совместим). Если
  функция рекомендаций Q05 (`librecommendation.so`) начнёт ругаться в логе — вынесу 1.17 под отдельным
  именем.
- **Озвучка.** Ответы озвучиваются через подменённый TTS‑движок (`RuIssTts`) в штатном плеере. Если
  многофразовые ответы обрываются — доработаю склейку сегментов (в v1 сегмент = одна фраза).

## Что внутри (для следующих сессий)
- Новые классы мода: `Q05/src/Q05Bridge.smali`, `Q05/src/RuIssTts.smali` (кладутся в dex мода → `classes4.dex`).
- Патчи штатных smali Q05: `Q05/tools/patch_q05.py` (7 точек — см. `Q05/PORT.md`).
- Сборка dex из smali: `Q05/tools/Assemble.java` (через библиотеку smali внутри apktool.jar).
- Склейка APK байт‑в‑байт + выравнивание: `Q05/tools/merge_apk.py`. Подпись: `Q05/tools/Sign.java` (platform test‑key).

Независимая модификация, не связана с Changan/Tinnove/iFlytek. На свой риск.
