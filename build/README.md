# Русский голосовой ассистент для Changan Q07 — сборка 2

Обновление относительно первой сборки: **распознавание больше не зависит от штатного события
«конец речи»** (на Q07 оно не приходит — поэтому команда не исполнялась). Теперь конец фразы
определяется по тишине в самом звуковом потоке, плюс добавлены подробные логи для диагностики.

Что в остальном — как в первой сборке: русский ASR (GigaAM‑v3), русская озвучка (TeraTTS ru_f2),
команды через штатный NLU, кнопка на руле, всё офлайн, без root. Подпись — те же AOSP test‑keys.

## Установка

1. `1_join.bat` — соберёт `SpeechAssistant-q07-ru.apk` (должно получиться **836 356 905 байт**).
2. Подключить голову по ADB.
3. `2_install.bat` — поставит и перезапустит ассистента.
4. Нажми кнопку голосового на руле **один раз**, дождись звука, скажи команду и **замолчи** —
   через ~0.8 сек тишины ассистент распознает и выполнит.

## Как проверить логом

```
adb logcat -c
adb logcat -s Q07Bridge:V GigaAsr:V Q07PiperCaTts:V Q07CaKey:V
```
Нажми кнопку, скажи «открой окно водителя», замолчи. Ожидаемая последовательность:
- `capture armed (key)` — запись пошла;
- `feedSr Ns ch=.. rms=.. speech=true ..` — **звук доходит** (rms растёт, когда говоришь);
- `endpoint (silence) bytes=..` — поймал конец фразы;
- `ASR: [открой окно водителя]` — распознал;
- `ru2zh … injectZh … : <кит.команда>` — ушло в штатный NLU → машина исполняет.

Если в `feedSr` **rms почти не меняется** при речи — звук в наш распознаватель не приходит
(тогда пришли лог, поправлю точку перехвата). Если `ASR: []` пустой при нормальном rms — вероятно
частота не 16 кГц: `adb shell settings put global stand_sr_rate 48000` и перезапуск ассистента.

## Тонкая настройка на устройстве (без пересборки)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `stand_sr_rate` | 16000 | частота потока распознавания (если каша — попробуй 48000/32000) |
| `stand_vad_silence_ms` | 800 | сколько тишины = конец фразы (увеличь, если обрывает рано) |
| `stand_vad_thresh` | 550 | порог «речь/тишина» по громкости (уменьши, если микрофон тихий) |
| `stand_vad_max_ms` | 10000 | максимальная длина фразы |
| `stand_wake_key` | 1 | кнопка на руле (0 — отключить) |

Применять: `adb shell settings put global <параметр> <значение>`, затем
`adb shell am force-stop com.incall.apps.speechassistant`.

## Откат

`adb uninstall com.incall.apps.speechassistant` — вернётся заводское приложение из /system.
